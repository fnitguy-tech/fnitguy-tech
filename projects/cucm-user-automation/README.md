# Cisco Unified Communications Manager (CUCM) User Automation

> Automate Cisco Unified Communications Manager (CUCM) user provisioning and Active Directory updates using Python, PowerShell, and the Cisco AXL API.

---

## Overview

Provisioning users in Cisco Unified Communications Manager (CUCM) can be repetitive and time-consuming, especially in larger enterprise environments. This project automates common administrative tasks by leveraging the Cisco AXL SOAP API to retrieve and process CUCM user information while integrating with Active Directory to keep user telephone numbers synchronized.

This repository serves as a documented and publicly shareable version of an internal automation project, making it easier for engineers to understand, deploy, and extend.

---

## Features

- Query CUCM using the Cisco AXL SOAP API
- Export existing CUCM user information
- Process user records using CSV files
- Map users to Device Pools, Calling Search Spaces, and Route Partitions
- Synchronize Active Directory telephone numbers
- Python automation with PowerShell integration
- Easily customizable for different CUCM deployments

## Configuration

Before running the automation, update the following values inside the Python script:

- CUCM Server URL
- AXL Username
- AXL Password
- WSDL File Location
- CSV Output Directory

All values intentionally use placeholder examples and should be replaced with your own environment.

---

## CSV Mapping File

The included `mappings.csv` file allows telephone number prefixes to be mapped to CUCM configuration values.

| Prefix | Device Pool | Calling Search Space | Route Partition |
|---------|-------------|----------------------|-----------------|
| 5551 | HQ-DP | HQ-CSS | HQ-PT |
| 5552 | Remote-DP | Remote-CSS | Remote-PT |

This allows the automation to assign users based on extension ranges rather than manually configuring each account.

---

## Active Directory Integration

The included PowerShell script updates the **telephoneNumber** attribute for Active Directory users using the CSV generated by the Python automation.

### Requirements

- RSAT Active Directory Module
- Permissions to modify Active Directory user objects
