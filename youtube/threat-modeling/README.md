# Threat Modeling for Normal People

Companion files for the Threat Modeling for Normal People YouTube video.

## Files

- Asset-Mitigation-Checklist.xlsx (Excel, Google Sheets)
- Asset-Mitigation-Checklist.ods (LibreOffice Calc)
- scripts/build_checklist.py (regenerates the .xlsx: `python build_checklist.py Asset-Mitigation-Checklist.xlsx`)

## What's inside

- Start Here: how to use it, a live scorecard, the threat modeling framework
- Definitions, Reducing Attack Surface, Common Attack Vectors (Verizon 2026 DBIR stats)
- Checklists: Devices, Accounts, Applications, Information (dropdowns, automatic gap counts and priorities)
- Resources
